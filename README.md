## 🌟 Key Features

* **🖥️ Interactive Bash Terminal Console:** A live Linux shell emulator supporting custom commands:
  * `whoami` — Displays identity, education, and technical orientation.
  * `skills` — Renders an organized matrix across Linux, Mobile, Networking, Web, and DevOps.
  * `projects` — Shows active production mobile and web builds with live links and repository endpoints.
  * `tree` — Interactive visual directory tree hierarchy of the engineering workspace.
  * `neofetch` — Visual ASCII system telemetry and environment specs.
  * `contact` — Quick developer connection links (Phone, WhatsApp, Email).
  * `sudo hire` — Interactive recruitment response with direct channel dispatch.
  * `clear` / `help` — Terminal utility controls.
* **🚀 Production Projects Showcase:**
  * **Nexora** — Cross-platform quick-commerce mobile app built with React Native 0.81, Expo SDK 54, and Expo Router v6.
  * **Kashmir Kesar Kingdom Pvt. Ltd.** — Flagship commercial B2B export & B2C web platform with 95% asset optimization and PWA offline caching.
  * **Craver Fast Food Co.** — Modular ES6+ online ordering web application with dynamic cart and checkout engine.
  * **Linux Administration & Automation Suite** — Robust Bash scripts for log rotation, permissions audit, and backup archiving.
  * **Network Protocol Labs** — Packet inspection, TCP handshakes, and CIDR subnet calculation.
  * **Python DSA Suite** — Time/space-optimized algorithms and data structure implementations.
* **📊 Comprehensive Skills Matrix:** Demonstrating core competencies across Linux Systems Administration, Computer Networking, Cross-Platform Mobile Engineering, Modern Web Architecture, Python Algorithms, and CI/CD.
* **📱 Bulletproof Responsive Design:** 100% responsive across smartphones, tablets, laptops, and ultra-wide desktop displays.
* **⚙️ Automated GitHub Actions CI/CD:** Automated deployment pipeline publishing directly to GitHub Pages.

## 🚀 How to Run Locally

### Option 1: Direct Browser
Simply double-click `index.html` in your file browser.

### Option 2: Local Web Server
```bash
git clone https://github.com/Uzair0123/portfolio.git
cd portfolio
python3 -m http.server 8000
```
Open `http://localhost:8000` in your web browser.
